Webhook Forward

Lê as requisições capturadas em um token do webhook.site e reenvia para uma URL local, preservando método, headers, query e corpo. Use para receber aqui webhooks de provedores que só aceitam URL pública (Certta, gateways, etc.): cadastre a URL https://webhook.site/<token> no provedor e aponte o destino para o serviço local. O destino é chamado de dentro do container, então use o hostname da greenn-network (ex.: http://greenn-back-nginx/api/...), não localhost.

Novo encaminhador

É o UUID da URL https://webhook.site/<token>.
Sem Api-Key o webhook.site limita a frequência; abaixo de 3000ms pode dar 429.
