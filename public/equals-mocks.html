Configure o EQUALS_API_BASE_URL=http://localhost:8115/equals-api no .env.dev do greenn-back para usar este mock. A autenticação Basic Auth é aceita sem validação de credenciais.
Endpoint: GET /equals-api/adquirentes
Formato: array de { "id": number, "nome": string }
Gateways mapeados: Pagarme, Cielo, Rede, PayPal, Pix, Ebanx, Stripe, Iugu, MercadoPago, Asaas, Dlocal, Worldpay, Efi
O campo nome é normalizado (minúsculo, sem pontuação) para comparação com o gateway da venda.
Endpoint: GET /equals-api/bandeiras
Formato: array de { "id": number, "nome": string }
O campo nome é comparado (case-insensitive) com a meta brand da venda.
Endpoint: GET /equals-api/formas-de-pagamento
Formato: array de { "id": string, "descricao": string }
Descrições esperadas: "Cartão de Crédito", "Pagamento Instantâneo", "Boleto Bancário", "Cartão de Débito"
A correspondência é feita pelo campo descricao exato.
Endpoint: GET /equals-api/meios-de-captura
Formato: array de { "id": number, "nome": string }
Obrigatório: deve existir um item com nome igual a "e-commerce" (case-insensitive) — é o meio de captura usado para todas as vendas online.
Endpoint: POST /equals-api/transacoes
Armazena os batches de transações enviados pelo greenn-back. Qualquer resposta JSON válida é retornada (o greenn-back ignora o retorno do POST).
