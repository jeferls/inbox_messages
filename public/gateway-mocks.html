Gateway Mocks

Substitui a API do gateway durante os testes locais: cada cenário do catálogo devolve uma resposta específica — recusa, erro do gateway, timeout — no mesmo formato da API real. Basta apontar a URL do gateway para cá e escolher o cenário; a request e a response de cada chamada ficam registradas no histórico.
# gateway/.env.dev — container-to-container, ambos na greenn-network WORLDPAY_API_URL=http://svc-inbox_messages/worldpay/paymentService # fixando um cenário direto na URL (ignora o cenário ativo) WORLDPAY_API_URL=http://svc-inbox_messages/worldpay/paymentService/fraud # ou, por request, sem mexer no .env X-Mock-Scenario: Teste Fraud
