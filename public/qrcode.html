Detalhes dos serviços

Comprar no checkout

Ofertas ativas do banco local — escolher gera o QR de compra.
O checkout abre pelo id do produto (http://IP:3000/<product_id>?offer=<hash>). Passar só o hash da oferta responde 200, mas a página vem vazia.

Preview no celular

Abre a URL do QR em aba nova, com moldura do aparelho.
A aba é servida pelo mesmo host do serviço, então o login funciona normalmente. User-agent e toque não são simulados — para isso use o device mode do DevTools (F12) ou o celular via QR Code.
Configuração da URL
IP da máquina na rede local. O celular precisa estar na mesma Wi-Fi.
Editável — o QR Code usa exatamente este valor.
