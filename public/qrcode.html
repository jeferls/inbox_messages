QR Code

Gera um QR Code apontando para um serviço local (greenn-adm, greenn-back, etc.) usando o IP da máquina na rede. O celular precisa estar na mesma rede Wi-Fi do notebook.

Preparar o ambiente

Rode na raiz do inbox_messages para reconfigurar greenn-adm e new-checkout com o IP da sua máquina:

make mobile-all
Só é necessário na primeira vez ou quando o IP da rede mudar. Depois disso, use os botões Subir / Parar abaixo. O greenn-back (81) e o gateway (82) precisam estar de pé.
Configuração da URL
IP da máquina na rede local.
Editável — o QR Code usa exatamente este valor.
